# Mini Hospital Management System

Sistem Informasi Manajemen Rumah Sakit Mini (Mini Hospital) berbasis web oleh Kelompok 5: Eriel, Dimas P., Dimas Agung, Anisa, Junita, dan M. Fahmi.

Proyek sistem informasi manajemen rumah sakit berskala mini yang dirancang untuk mengelola alur data layanan kesehatan secara terintegrasi, efisien, dan terstruktur.
